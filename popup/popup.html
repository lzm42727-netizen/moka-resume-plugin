关于

Moka 智能简历筛选助手

版本：…

这是一个基于 AI 的 Moka 候选人智能筛选插件。

主要功能

  • 自动识别候选人信息
  • 按硬性门槛与经历匹配给出决策分
  • 侧栏实时显示匹配评分与证据卡
  • 筛选可切到其他浏览器标签；刷新后可确认续筛
  • 本岗校准与历史偏好会进入下一轮评分

如何使用

  1. 先在「设置」标签页配置 API Key
  2. 打开 Moka 候选人管理页面
  3. 点扩展图标打开右侧栏，选择职位并填写门槛与关键词
  4. 点击「开始筛选」
  5. 在「结果」标签页查看评分，点卡片打开候选人

隐私保护

  • API Key 只保存在浏览器本地存储
  • 评分时候选人画像会发送到你配置的 LLM 服务；合规敏感场景请用内网或本地模型
  • 自定义 Endpoint 首次使用时，Chrome 会申请访问该域名
