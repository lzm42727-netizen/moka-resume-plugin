ℹ️关于

Moka 智能简历筛选助手

版本：1.5.10

这是一个基于 AI 的 Moka 候选人智能筛选插件。

主要功能

  • 自动识别候选人信息
  • AI 智能匹配 JD 要求
  • 侧栏实时显示匹配评分
  • 提供个性化建议
  • 支持权重自定义

如何使用

  1. 先在「设置」标签页配置 API Key
  2. 打开 Moka 候选人管理页面
  3. 点扩展图标打开右侧栏，选择职位和权重
  4. 点击「开始筛选」
  5. 在「结果」标签页查看评分，点卡片打开候选人

隐私保护

  • 所有数据只在本地处理和保存
  • API Key 只保存在浏览器本地存储
  • 不会上传个人信息到第三方服务器
