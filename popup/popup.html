ℹ️关于

Moka 智能简历筛选助手

版本：1.4.1

这是一个基于 AI 的 Moka 候选人智能筛选插件。

主要功能

  • 自动识别候选人信息
  • AI 智能匹配 JD 要求
  • 实时显示匹配评分
  • 提供个性化建议
  • 支持权重自定义

如何使用

  1. 先在「设置」标签页配置 API Key
  2. 打开 Moka 候选人管理页面
  3. 选择要匹配的职位和权重
  4. 点击「开始筛选」按钮
  5. 等待 AI 评分完成

隐私保护

  • 所有数据只在本地处理和保存
  • API Key 只保存在浏览器本地存储
  • 不会上传个人信息到第三方服务器
