# Moka 智能简历筛选助手

一个强大的 Chrome 插件，帮助 Moka 招聘系统用户智能筛选候选人，自动匹配职位 JD 要求并提供 AI 驱动的评分和建议。

## ✨ 主要功能

- 🔍 **自动识别候选人** - 自动识别 Moka 页面上的候选人卡片和信息
- 📊 **AI 智能匹配** - 基于 LLM 对候选人与职位 JD 进行智能匹配分析
- ⭐ **实时评分展示** - 在候选人卡片右侧显示匹配评分和等级
- 💡 **个性化建议** - 提供 3-5 条关键匹配建议，帮助决策
- ⚙️ **灵活权重配置** - 支持自定义评分权重，区分正式员工和实习生
- 🔐 **隐私保护** - 所有数据本地处理，API Key 不会上传到第三方

## 📋 系统要求

- Chrome 浏览器 (版本 88+)
- 有效的 LLM API Key (OpenAI、Claude 等)
- Moka 招聘系统账号

## 🚀 安装步骤

### 1. 克隆或下载项目

```bash
git clone https://github.com/yourusername/moka-resume-plugin.git
cd moka-resume-plugin
```

### 2. 在 Chrome 中加载

1. 打开 Chrome，进入 `chrome://extensions/`
2. 启用右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择项目文件夹

### 3. 配置 API

1. 打开 Moka 系统 (https://app.mokahr.com)
2. 点击浏览器工具栏中的插件图标
3. 切换到「⚙️ 设置」标签页
4. 填入以下信息：
   - **API 提供商**: OpenAI / Claude / 自定义 API
   - **API Endpoint**: 你的 API 接口地址
   - **API Key**: 你的 API Key
   - **模型名称**: 如 `gpt-4o`、`claude-3-sonnet`
5. 点击「🧪 测试 API」验证连接
6. 点击「💾 保存设置」

## 📖 使用指南

### 基本流程

1. **打开 Moka 候选人管理页面**
   - 登录 https://app.mokahr.com/dashboard
   - 进入「候选人管理」模块
   - 确保页面显示有候选人列表

2. **打开筛选面板**
   - 点击浏览器工具栏的插件图标
   - 切换到「🧑‍💼 筛选」标签页

3. **配置筛选参数**
   - **选择职位**: 从下拉列表中选择要匹配的职位
   - **选择职位类型**: 正式员工 / 实习生
   - **调整权重**: 根据职位要求调整三个维度的权重
     - 学历要求权重 (0-100%)
     - 工作经验权重 (0-100%)
     - 技能匹配权重 (0-100%)
   - 权重总和应该为 100%（系统会提示）

4. **开始筛选**
   - 点击「🚀 开始筛选」按钮
   - 等待 AI 完成评分（可能需要几分钟，取决于候选人数量）
   - 进度条会实时显示处理进度

5. **查看结果**
   - 每个候选人卡片的右侧会显示评分卡片
   - 包含：
     - 📊 总体匹配分数 (0-100)
     - 🏷️ 匹配等级 (强烈推荐/值得考虑/一般/不推荐)
     - 💬 3-5 条关键建议

### 权重配置示例

**对于产品经理职位（重视经验）：**
- 学历要求: 20%
- 工作经验: 50%
- 技能匹配: 30%

**对于校园招聘实习生（重视学历）：**
- 学历要求: 50%
- 工作经验: 10%
- 技能匹配: 40%

## 🎯 评分说明

| 分数范围 | 等级 | 说明 |
|---------|------|------|
| 90-100 | 🟢 **强烈推荐** | 候选人条件完全符合职位要求 |
| 70-89 | 🟡 **值得考虑** | 候选人基本符合要求，有部分优势 |
| 50-69 | 🟠 **一般** | 候选人符合部分要求，有一定差距 |
| 0-49 | 🔴 **不推荐** | 候选人与职位要求差异较大 |

## ⚙️ 高级功能

### 自动保存评分

启用「自动保存评分到备注」选项后，评分会自动保存到 Moka 系统中候选人的备注字段。

### 自定义 API

如果你有自己的 LLM 服务（如本地部署的 Ollama），可以：
1. 在设置中选择「自定义 API」
2. 填入你的 API Endpoint
3. 设置正确的模型名称

## 🐛 故障排除

### 问题1：无法识别候选人卡片

**解决方案**：
- 确保你在 Moka 的候选人管理页面
- 页面中必须显示有候选人列表
- 尝试刷新页面后重新开始筛选
- 检查浏览器控制台 (F12) 的错误日志

### 问题2：API 连接失败

**解决方案**：
1. 检查 API Key 是否正确
2. 确认 API Endpoint 是否正确（推荐使用官方接口）
3. 检查网络连接
4. 尝试在设置页面测试 API 连接
5. 检查 API 配额是否已耗尽

### 问题3：评分显示不完整

**解决方案**：
- 尝试刷新页面
- 清除浏览器缓存
- 重新加载插件 (chrome://extensions 中点击刷新按钮)

### 问题4：筛选速度很慢

**解决方案**：
- 这是正常的，取决于 API 响应速度
- API Key 可能有速率限制，建议升级账户等级
- 考虑分批处理，每次筛选较少的候选人

## 💬 常见问题 (FAQ)

### Q: 如何获得 API Key?

**A**: 根据你选择的 LLM 提供商：

- **OpenAI**: https://platform.openai.com/account/api-keys
- **Claude (Anthropic)**: https://console.anthropic.com/account/keys
- **其他服务**: 查看相应服务的文档

### Q: 会产生多少 API 费用?

**A**: 费用取决于：
- 你的 API Key 对应的价格表
- 评分的候选人数量
- 每条评分消息的 token 使用量（通常 200-500 tokens）

建议在设置中测试 API 以了解实际成本。

### Q: 能否支持离线评分?

**A**: 暂不支持离线评分，因为依赖于 LLM 服务。但你可以使用本地部署的 LLM（如 Ollama），然后在设置中配置自定义 API Endpoint。

### Q: 评分的准确度如何?

**A**: 准确度取决于：
- 候选人信息的完整性
- 职位 JD 的清晰度
- 使用的 LLM 模型质量

建议将 AI 评分作为参考，最终招聘决策还需人工审核。

## 🔒 隐私和安全

- ✅ **本地存储** - 所有候选人数据只在你的浏览器中处理，不上传到任何服务器
- ✅ **API Key 保护** - API Key 只保存在浏览器本地存储，使用 HTTPS 安全传输
- ✅ **无数据收集** - 插件不收集任何用户数据或使用分析
- ✅ **开源透明** - 代码完全开源，你可以查看和审计所有逻辑
