# Moka 智能简历筛选助手

一个强大的 Chrome 插件，帮助 Moka 招聘系统用户智能筛选候选人，自动匹配职位 JD 要求并提供 AI 驱动的评分和建议。

## ✨ 主要功能

- 🔍 **自动识别候选人** - 自动识别 Moka 页面上的候选人卡片和信息
- 📊 **AI 智能匹配** - 基于 LLM 对候选人与职位 JD 进行智能匹配分析
- ⭐ **实时评分展示** - 在候选人卡片右侧显示匹配评分和等级
- 💡 **个性化建议** - 提供 3-5 条关键匹配建议，帮助决策
- ⚙️ **灵活权重配置** - 支持自定义评分权重，区分正式员工和实习生
- 🔐 **本地存储配置** - API Key 只保存在浏览器本地，不上传到第三方服务器

## 🆕 v1.1 更新

- **API 调用统一到后台 Service Worker**：避开 Moka 页面 CSP 对 content script `fetch` 的拦截。
- **多 Provider 适配**：OpenAI / Claude / 自定义（OpenAI 兼容）三种协议均可正确调用。
- **健壮的 JSON 解析**：正确处理代码块、多余文字、嵌套的建议数组。
- **并发 + 指数退避重试 + 结果缓存**：更快、更稳、避免对同一候选人重复扣费。
- **评分卡渲染修复**：结构与配色按分数区分。
- **非 Moka 页面容错**：popup 会给出明确提示，而不是静默失败。

> ⚠️ **关于 DOM 识别**：候选人/职位/JD 的抓取选择器目前仍是占位实现（代码中标记为 `TODO(moka-dom)`），需要根据真实 Moka 页面结构或接口来替换后才能在生产环境正常识别数据。

## 📋 系统要求

- Chrome 浏览器 (版本 88+)
- 有效的 LLM API Key (OpenAI、Claude 等)
- Moka 招聘系统账号

## 🚀 安装步骤

### 1. 克隆或下载项目

```bash
git clone https://github.com/lzm42727-netizen/moka-resume-plugin.git
cd moka-resume-plugin
```

### 2. 在 Chrome 中加载

1. 打开 Chrome，进入 `chrome://extensions/`
2. 启用右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择项目文件夹

### 3. 配置 API

1. 打开 Moka 系统 (https://app.mokahr.com)
2. 点击浏览器工具栏中的插件图标
3. 切换到「⚙️ 设置」标签页
4. 填入以下信息：
   - **API 提供商**: OpenAI / Claude / 自定义 API
   - **API Endpoint**: 你的 API 接口地址
   - **API Key**: 你的 API Key
   - **模型名称**: 如 `gpt-4o`、`claude-3-5-sonnet-latest`
5. 点击「🧪 测试 API」验证连接
6. 点击「💾 保存设置」

## 📖 使用指南

### 基本流程

1. **打开 Moka 候选人管理页面**
2. **打开筛选面板**：点击插件图标 → 「🧑‍💼 筛选」
3. **配置筛选参数**：选择职位 / 职位类型 / 调整三个维度权重（总和建议 100%）
4. **开始筛选**：点击「🚀 开始筛选」，进度条实时显示
5. **查看结果**：每个候选人卡片右侧显示总分、等级和 3-5 条建议

## 🎯 评分说明

| 分数范围 | 等级 | 说明 |
|---------|------|------|
| 75-100 | 🟢 **强烈推荐** | 候选人条件高度符合职位要求 |
| 50-74 | 🔵 **值得推荐** | 候选人符合要求，值得进一步沟通 |
| 35-49 | 🟠 **一般** | 候选人符合部分要求，有一定差距 |
| 0-34 | 🔴 **不推荐** | 候选人与职位要求差异较大 |

## 🐛 故障排除

- **无法识别候选人卡片**：确认在候选人管理页面；DOM 选择器仍为占位实现，需接入真实 Moka 结构。
- **API 连接失败**：检查 Key / Endpoint / 网络 / 配额；用「测试 API」排查。
- **筛选很慢**：受 API 响应与限流影响，已内置并发与退避重试。

## 🔒 隐私和安全

- ✅ **配置本地存储** - API Key 与设置只保存在浏览器本地存储，不上传到任何第三方服务器。
- ⚠️ **评分需调用 LLM** - 为了评分，候选人信息会发送到**你自己配置的** LLM 服务（如 OpenAI / Claude / 你的自建服务）。若对数据合规敏感，建议使用本地部署的模型（如 Ollama）并在设置中配置为自定义 API。
- ✅ **无额外数据收集** - 插件不收集任何使用分析。
- ✅ **开源透明** - 代码完全开源，可自行审计。
