# Moka 智能简历筛选助手

Chrome 插件：在 Moka 候选人列表页批量拉取简历，按硬性条件标注，用 AI 做四维度评分并给出推荐等级与理由。

## ✨ 主要功能

- **接口拉取候选人** — 捕获并重放 Moka 列表接口，支持分页与「本轮筛选人数」
- **详情补全经历** — 自动补全实习 / 项目等结构化经历（`practiceInfo` / `projectInfo` 等）
- **硬性条件本地判定** — 学历、院校、经验、性别、年龄、实习经验等；不满足会标注置底，但仍会 AI 打分
- **JD 解读 + 四维度评分** — 经验 / 技能 / 教育 / 潜力；权重可由 AI 建议，也可手动调整
- **结果浮层** — 右侧面板展示综合分、等级、分维度分数与亮点 / 差距
- **多 Provider** — OpenAI / Claude / 自定义（OpenAI 兼容）接口
- **本地存储配置** — API Key 只保存在浏览器本地

## 📋 系统要求

- Chrome 88+
- 可用的 LLM API Key（OpenAI、Claude 或 OpenAI 兼容服务）
- Moka 账号，并在 `https://app.mokahr.com` 的**候选人列表**页使用

## 🚀 安装步骤

### 1. 克隆或下载

```bash
git clone https://github.com/lzm42727-netizen/moka-resume-plugin.git
cd moka-resume-plugin
```

### 2. 在 Chrome 中加载

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本项目文件夹
4. 代码更新后：扩展页点「重新加载」，并**刷新 Moka 页面**

### 3. 配置 API

1. 打开 Moka，点击工具栏插件图标 → 「⚙️ 设置」
2. 填写提供商、Endpoint、API Key、模型名称
3. 「🧪 测试 API」通过后「💾 保存设置」

自定义 Endpoint 可填到 `/v1`；插件会按需补全 chat 路径。首次访问新域名时，请允许浏览器弹出的 host 权限。

## 📖 使用指南

1. 打开目标职位的**候选人列表**（如初筛）
2. **（强烈建议）先点开任意一位候选人姓名进入详情一次**，再回列表——用于捕获详情接口，保证实习 / 项目经历能补全
3. 插件弹窗 → 「🧑‍💼 筛选」：选职位、正式员工 / 实习生、本轮人数
4. 检查硬性条件与四维度权重（可由 JD 预填 / 建议）
5. 「🚀 开始筛选」，在页面右侧浮层查看结果

## 🎯 评分说明

| 分数范围 | 等级 | 说明 |
|---------|------|------|
| 75–100 | 🟢 **强烈推荐** | 高度符合，优先沟通 |
| 50–74 | 🔵 **值得推荐** | 基本符合，值得推进 |
| 35–49 | 🟠 **一般** | 部分符合，差距明显 |
| 0–34 | 🔴 **不推荐** | 匹配度偏低 |

面板标题中的「推荐 N」= 综合分 ≥ 50 的人数。

## 🐛 故障排除

- **未找到候选人 / 拉取很少**：确认在候选人列表页并刷新；调大「本轮筛选人数」或选「全部」；先让列表加载出搜索请求再筛选。
- **提示先点开候选人 / 经历补不全**：在列表点开任意一人详情一次后重试；看状态是否出现「已补全经历 N 位」。
- **API 连接失败**：检查 Key、Endpoint、网络与配额；用「测试 API」；新域名需授权。
- **无法解析模型返回**：重新加载扩展后重筛（解析失败不写缓存）；可换指令跟随更稳的模型。
- **筛选很慢**：人数 × AI 调用量较大时属正常；可减小本轮人数或点「停止」。

## 🔒 隐私和安全

- ✅ API Key 与设置只保存在浏览器本地存储
- ⚠️ 评分时候选人画像会发送到**你配置的** LLM 服务；合规敏感场景请用内网或本地模型
- ✅ 插件不另行收集使用分析；代码可自行审计
