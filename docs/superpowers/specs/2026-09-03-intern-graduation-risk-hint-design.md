# 实习岗毕业临近风险提示（规格）

日期：2026-09-03  
状态：已实现

## 目标

实习岗候选人背景可以很好，但毕业太近时没法实习太久。评分卡目前要么不提，要么把「可连续实习 N 个月」交给模型，写成「未明确……」。招聘官要的是：**分数不动，卡片上本地标出「毕业 YYYY.MM，距今不足半年」。**

黄芯怡这类样本：经历匹配 73 仍可推进；教育经历结束日 2026.12；在 2026-09-03 筛时应出现该提示。

## 非目标

- 不改决策分、档位、排序、加分看。
- 不把可实习时长做成硬门槛，不封顶 49。
- 不改手写门槛「连续实习 8 个月」的模型判定（可仍出现在未体现里）。
- 正式岗不出这条提示（马上毕业对正式岗常是到岗优势）。
- 结束日缺失、已毕业、或距毕业满半年及以上：不提示、不猜测。
- 本规格不改 CSV 导出列、不改本岗校准。

## 谁看到、何时算

- 仅 `jobType === 'intern'`。
- 本地根据 `app.educationInfo`（及兼容字段）取**最晚结束日**，相对「今天」（日期，不计时）比较。
- 在 content 筛人时算一次，写入结果 item，随侧栏 snapshot / 本岗存档走。不要在 popup 里再去读已被 slim 掉的 `educationInfo`。

## 判定

取每条教育经历的 `endDate` / `endTime` / `end` / `to`。

- 解析到年月即可：`2026.12`、`2026-12`、`2026/12`、`2026-12-01` 都有效；只有年月时按该月**最后一天**。
- 「至今」「现在」「present」或空：该条不参与比较。
- 多条教育经历：用解析成功的日期里**最晚**的一条（在读硕士结束日优先于已读本科）。
- **出提示**当且仅当：最晚结束日 ≥ 今天，且最晚结束日 **早于** 今天加 6 个日历月（不足半年，满半年不出）。
- 结束日早于今天（已毕业）：不出。
- 一条都解析不出：不出。

## 文案与位置

固定一句，带上毕业年月，方便核对：

> 毕业 2026.12，距今不足半年

- 结果卡片：姓名行下方、学历 meta 附近，独立一行/标签，样式用风险提示（琥珀/橙色），**不要**进「具备 / 未体现」，也**不要**进门槛红标列表（那些会改变「未过门槛」语义）。
- `title` 可写「实习岗档期风险，不影响分数」。
- 评分失败卡、尚未出分的卡：只要 item 上已有该字段且当前岗位是实习，同样显示（日期与 AI 无关）。

## 数据

`lib/match.js` 增加纯函数，例如：

```js
graduationRiskHint(educationList, { jobType, now })
// intern + 不足半年 → { endLabel: '2026.12', text: '毕业 2026.12，距今不足半年' }
// 否则 → null
```

content 写入 `item.graduationRisk`。`toResultView`、`slimScreeningItem` / `hydrateScreeningItem` 原样带上该对象。历史决策卡若旧存档没有该字段，不补算、不显示。

## 测试（独立推导，不固化当前输出）

- 今天 2026-09-03，结束 2026-12 → 有提示，文案含 `2026.12`。
- 今天 2026-09-03，结束 2027-03-03（恰好 6 个月）→ 无提示。
- 今天 2026-09-03，结束 2026-08-01（已毕业）→ 无提示。
- `jobType: 'full-time'` 即使 2026-12 毕业 → 无提示。
- 结束日空 / 「至今」→ 无提示。
- 本科 2025-07 + 硕士 2026-12 → 用 2026.12。
- `composeFinalScore` 的 score / level 在有提示时与无提示时相同。
- popup 渲染：实习结果视图带 `graduationRisk.text` 时出现该文案；不出现在具备/未体现列选择器里。

## 成功标准

打开实习岗结果卡：黄芯怡仍是 73 / 可推进；卡片能看见「毕业 2026.12，距今不足半年」。换正式岗或毕业日在 6 个月外，没有这条。
