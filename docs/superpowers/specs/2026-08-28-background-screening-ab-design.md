# A+B：筛选可切走 + 断点续筛（侧栏确认）

日期：2026-08-28  
状态：已批准（续筛交互选 **B：侧栏确认**）

## 目标

1. **A**：开筛/决策时说清「Moka 标签要开着」；筛选正常完成后可桌面通知（可关）。
2. **B**：筛选中刷新或 content 重载后，侧栏提示「发现未完成的筛选，是否继续？」；确认后只评未完成的人；错岗则暂停。

## 非目标

- 不把推荐/淘汰做成无人值守队列。
- 不要求关掉 Moka 标签仍能筛完。
- 不默认静默自动续跑。

## 行为摘要

| 事件 | 行为 |
|------|------|
| 开始筛选 | 状态栏提示可切其他浏览器标签；写入 `mokaScreeningJob`（running） |
| 评完一人 | 更新 job.completed + 现有 screening 落盘 |
| 正常完成 | job→done；可选桌面通知；停 keepalive |
| 停止 | job→stopped；清 running |
| content 重载且 job=running、本岗匹配、有未评分人 | 发 `screeningResumeAvailable` → 侧栏确认条 |
| 用户点「继续筛选」 | `resumeScreening`：只处理无分/错误分项 |
| 用户点「放弃」 | job→stopped；保留已落盘结果 |
| 筛选中页面 jobId 与任务不一致 | 暂停，job→paused_mismatch，侧栏提示 |

## 成功标准

- 切去其他标签多数情况能跑完并（在开通知时）收到完成通知。
- 刷新后出现确认条，确认后续跑，已评分人不丢。
- 关「筛选完成时通知」后不弹通知。
- 不续筛、不刷新时，现有开筛/推荐路径不变。
