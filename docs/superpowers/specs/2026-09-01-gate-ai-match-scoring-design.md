# 硬性门槛 + AI 匹配打分（规格）

日期：2026-09-01  
状态：待实现（讨论已锁定，实现前以本文为准）

## 目标

所有岗位共用一套规则，不按「日语岗 / 后端岗」分叉算法。

- **能不能推进**：两条都要过。硬性门槛有未过 → 综合分最高 49。门槛全过（或没配门槛）→ 综合分等于匹配分，实习/技能差则可以低于 50，档位仍按 50 / 80 切。
- **能推进的人谁更好**：匹配分高的排前面；≥80 优先推进。
- **筛选关键词**：只给模型当重点，不参与门槛，也不做加减分。

招聘官填写什么，就按什么审核。学历勾「本科」、语言写「日语 N1」、专业写「设计类相关专业」，核对标准就是这些字面条件。上述字段均可从 JD 提取后预填，招聘官再改。

## 非目标

- 不再使用「必须 / 重要 / 加分」三栏计分（必须栏取消，避免与硬性门槛重叠）。
- 不再用经验 / 技能 / 教育 / 潜力四维加权作为综合分来源。
- 模型不再复审已由硬性门槛判定的学历、院校、年龄、性别、年限或实习时长。

## 配置区

### 硬性门槛

未勾选、未填写的项不参加门槛。

固定项（空 = 不限）：

- 学历
- 院校（可多选；候选人命中任一已选项即过）
- 年龄（可多选区间；落在任一已选区间即过）
- 性别
- 工作年限（正式员工）或实习时长 / 是否需实习经验（实习生，随职位类型显示）

可手写、可多条（空 = 不卡）：

- **语言**：如 `日语`、`日语 N1`、`英语 CET6`。填「日语」则简历能证明会日语即过；填「日语 N1」则必须达到 N1（或等价表述）。
- **专业及其他**：如 `设计类相关专业`、`一周到岗 5 天`。按填写的完整条件核对。

从 JD 预填时：已能映射到学历 / 年限等下拉的，只填下拉，不要再生成一条重复的手写门槛。语言、专业、到岗天数等下拉没有的，进手写门槛。

### 筛选关键词（不算门槛、不算分）

两组，均可从 JD 提取，可改：

- **重点看**：希望模型在匹配说明里优先核对的经历 / 技能。
- **加分看**：有则更好、没有不卡的点。

写入评分 prompt，作为关注点；不按条数加减分。两组都空时，模型只对照 JD / 岗位理解打匹配，仍可开筛。

## 计分

门槛只负责「封顶」，不再「托底」。

```
未过条数 = 已填写的硬性门槛里判定为未过的条数

若 未过条数 ≥ 1：
  综合分 = max(0, 49 − 7 × 未过条数)
  // 匹配分再高也不超过 49

若 未过条数 = 0：（含一条门槛都没配）
  综合分 = clamp(匹配分, 0, 100)
  // 不再托到 50
```

未过条数与分数对照：1→42，2→35，3→28，4→21，5→14，6→7，7 及以上→0。

因此：

- 本科过了、实习和技能很差、匹配分 32 → 综合分 32，**不建议推进**（卡片说明匹配不足，不是学历未过）。
- 本科过了、经历对口、匹配分 71 → 可推进。
- 日语未过、匹配分 90 → 综合分 42，不建议推进。
- 没配门槛 → 综合分 = 匹配分。

匹配分由模型给出 0–100 的整数，只表示经历/技能与 JD、重点看的对口程度。

简历上完全看不到某条已配手写门槛所需证据 → 该条算未过。

开筛不要求必须先配门槛。未配时结果卡片不展示「未过门槛」列。0–49 时卡片须区分原因：有未过门槛则列出门槛；门槛全过则标明「经历/技能匹配不足」。

## 推荐与展示

名单按综合分从高到低。卡片需能直接读懂分数：综合分、匹配分、档位、未过门槛列表（硬性门槛合并为一列，含语言 / 专业手写项）、匹配项、未匹配项（来自模型；关键词命中情况可出现在这两列里）。

档位（先按下列分数切，实现时写死，不做成设置项）：

| 综合分 | 档位 | 含义 |
|--------|------|------|
| 0–49 | 不建议推进 | 门槛未过，或门槛已过但实习/技能匹配差 |
| 50–79 | 可推进 | 门槛已过（或未配门槛），且匹配尚可 |
| 80–100 | 优先推进 | 匹配明显强 |

## 谁来判定过 / 不过

公式成立的前提是「未过条数」可信。两类门槛分开判：

| 门槛 | 谁判 | 说明 |
|------|------|------|
| 学历、院校、年龄、性别、年限 / 实习时长 | 本地对照简历字段 | 模型不再复审，避免判两次 |
| 语言、专业及其他（手写） | 模型逐条输出过 / 不过 + 一句依据 | 「会 PS」「英语很好」「设计类专业」无法靠字段精确核对 |

手写项判定规则：按招聘官写下的字面条件；简历无证据 → 不过。模型对门槛只输出过/不过，**不把门槛结果写进匹配分**（匹配分仍只表示 JD 适合度）。综合分再按上文公式合成。

**不要把手写门槛写成过于含糊的「有相关实习经验」。**  
「相关」没有核对标准，当门槛会误杀或形同虚设。这类诉求放进「重点看」，用匹配分拉开。门槛请写成可核对的句子，例如 `至少一段设计相关实习`、`日语 N1`、`会使用 Photoshop`。

## 三类岗位自测（同一公式）

### 1. 强门槛（日语实习 / 设计实习 / 海外运营）

配置举例：

- 日语实习：语言 `日语`
- 设计实习：专业及其他 `会使用 Photoshop` + `设计类相关专业`
- 海外运营：语言 `英语流利`（不要只写「英语很好」却无等级时，接受模型按「流利」理解）

自测：

- 不会日语 / 不会 PS / 英语看不出 → 至少 1 条未过 → 综合分 ≤ 42，不建议推进；匹配分可以很高，也抬不过 49。
- 门槛全过、实习/技能很差 → 匹配分低于 50 → 综合分低于 50，不建议推进。
- 门槛全过、对口一般 → 50–79，可推进。
- 门槛全过且内容/设计/海外运营明显对口 → ≥80，优先推进。

### 2. 弱门槛（本科 + 只要女生 + 希望有相关实习）

配置举例：学历本科、性别女。「相关实习」放 **重点看**，不放硬性门槛。

自测：

- 男或大专 → 未过门槛 → ≤49，不建议推进。
- 女本科、实习/技能不对口 → 门槛已过，但匹配分低于 50 → 不建议推进。
- 女本科、实习对口一般 → 可推进。
- 女本科、实习很对口 → 可到优先推进。

若把「有相关实习」也写成手写门槛，则没有相关实习的女本科会直接 ≤42。该岗若本意是「门槛不强」，不要这样配。

### 3. 无门槛（看实习与技能）

硬性门槛全空；重点看填实习方向和技能（也可只靠 JD）。

自测：

- 综合分 = 匹配分。
- 无相关实习、技能不对口 → 可低于 50，不建议推进。
- 实习与技能明显对口 → 可到 80+。
- 不出现「人人至少 50 分」。

## 仍须接受的边界

- 手写门槛的过/不过依赖模型，偶发误判（把 Photoshop 写成「修图」应判过；实现时 prompt 要求认同义说法）。
- 性别作为门槛有合规风险，产品仍按招聘官勾选执行，不做自动取消。


## 模型职责

输入：JD（或岗位理解）、候选人简历、本岗「重点看 / 加分看」、本岗手写门槛列表。

输出：

- 每条手写门槛：过 / 不过 + 一句依据
- 匹配分（0–100，只表示与 JD / 关键词的适合度，不含已由本地判定的学历等）
- 匹配列表、未匹配列表

不要输出「因学历未过所以低分」这类已由下拉门槛处理的结论。

## 成功标准

- 日语实习：语言门槛写「日语」，简历无日语 → 综合分 ≤ 42 且不建议推进；有日语但运营经历很差 → 匹配分低于 50，不建议推进；有日语且经历对口 → ≥50 可推进，明显强则 ≥80 优先推进。
- 只勾本科：全是本科但实习很差 → 不是人人 50，匹配差则低于 50、不建议推进。
- 未配任何硬性门槛：综合分 = 匹配分；匹配 40 为不建议推进，匹配 65 为可推进，匹配 85 为优先推进。
- 任意岗位同一公式，只换门槛内容和 JD。
- 招聘官能用「未过哪几条门槛」+「匹配/未匹配」解释综合分，不必理解四维权重或芯片加减分。
